# Draft the daily review note

Inputs: accepted changes, source health, current records and expiry alerts.
Do not create new facts. Lead with meaningful changes and decisions needed.
For each item show opportunity ID, previous state, new evidence and event
date, Canadian implication, next validation task and source link/locator.

Group new leads, material updates, approaching expiries, negative changes
and source coverage. Omit repetitive commentary. Preserve uncertainty and
amount type. An absence of alerts is not no change if coverage failed.
Never send the draft or automatically promote a Top Ask.
